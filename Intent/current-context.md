# 現在の判断で作業できること

開発者とAIが、現在有効な目的・制約・仕様を必要な範囲で把握し、過去の案と混同せず作業できるようにする。

現在仕様を対象ごとに低コストで把握し、必要ならその目的へ辿れるようにする。検討と実装では必要な情報を分け、通常の実装で目的を再解釈して仕様を変えてしまうことを避ける。状態の把握のために別の正本や同期保守の負担を増やさない。

現在の判断を理解するための理由やトレードオフは現行文書に残す。過去の変更経緯や未採用案が、現在の指示として読み込まれる状態を避ける。

ОЗУМリポジトリ全体を、ОЗУМ自身を適用して検証できるリファレンス実装として扱う。配布用のSkills・開発手法テンプレートは、その中で管理する成果物であり、リファレンス実装と同義にしない。
