# Feature Spec

Feature Specは、対象Featureが現在満たすべき振る舞い・契約、必要な制約、検証可能な受入条件の正本です。関連するIntentへ相対リンク等で辿れるようにします。目的や望む理由の正本はIntentに置き、仕様には現在の判断を理解するために必要な理由だけを残します。

新規の仕様はFeature単位のMarkdownとしてここへ置けます。固定の見出し・スキーマ・ID・メタデータは要求しません。既存の文書、AGENTS、Skill、設定が仕様を直接表現できていれば、その場所を正本として使い、移動・複製しません。全実装要素に一対一の仕様を作る必要もありません。

ファイル名・見出し・検索を入口とし、必要な仕様からIntentへ辿ります。Intent側の逆リンク、手書きの仕様一覧、完全な対応表は保守しません。採用済みの要求は実装済みであることを意味しません。実装状態が必要なら仕様と対象コード・testsから確認します。

過去の仕様・未採用案・議論経緯は追記せず、必要なときだけ対象仕様や実装のGit履歴、任意のIssueを参照します。検討・決定・実装時の読み方は [AGENTS.md](../AGENTS.md) に従います。
